# Summit Leads Website

Marketing website for Summit Leads Ltd — digital growth, software development and AI automation.

## Stack
- Next.js 15 / React 19
- TypeScript
- Tailwind CSS v4 (with custom responsive CSS)
- Designed for Vercel deployment

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Brand assets
The logo and founder portrait are currently referenced from this repository's public raw GitHub asset URLs:
- `summit-leads-cropped.png`
- `image_3mb.png`

For production, move these into `public/images/` and update the image paths if desired.

## Contact form
The enquiry form opens the visitor's email application using `mailto:hello@summitleadsltd.com`. Confirm that this mailbox exists or replace it with the preferred enquiry address before launch. A server-backed form endpoint can be added later.
